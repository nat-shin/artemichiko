# 9 — ArteMichiko · Investigación: Skills de Diseño de Medio Oriente (Elegancia · Oro · Lujo Árabe/Persa)

> Dirección de diseño objetivo: **BLANCO + NEGRO + DORADO (oro brillante) → ELEGANCIA**.
> Investigación con **Firecrawl + Tavily** (ambos), **GitHub search** y ecosistemas de skills (skills.sh, Anthropic, awesome-claude-skills, typeui.sh, awesome-design-skills).
> Fecha: 2026-08-13.

## 0. Resumen ejecutivo

- **No existe una skill "nativa" de lujo oro/negro Medio Oriente lista para instalar.** El ecosistema tiene skills de *lujo genérico* (premium/refined/editorial) y un cluster **emergente de skills árabes** (RTL, tipografía árabe, identidad de marca GCC) de alta calidad y muy recientes (2026).
- La combinación ganadora = **base premium genérica (mega-frontend-design / awwwards-skill / typeui)** + **capa de corrección árabe (arabic-design)** + **tokens propios de oro/negro/blanco**.
- Hay **recursos algorítmicos sólidos** para generar geometría islámica/arabesque propia (girih, estrellas de 8 puntas) en SVG — único, no stock.
- Referencias regionales de lujo reales: **Diriyah, NEOM, Al Trad (Riad), Qatar Gold, A4DH (Emiratos)** — confirman la paleta negro/crema/oro y la estética "heritage maximalism".

## 3. Las 8 mejores para adoptar / adaptar

Orden por impacto + esfuerzo para ArteMichiko (blanco+negro+dorado, elegancia):

1. **mega-frontend-design** (FerasMahmoud) — **ADOPTAR como base de diseño web.** Trae arquetipo *Art Deco/Geometric* ("gold/brass, Gatsby-era") que conecta directo con lujo árabe; tokens OKLCH editables; RTL/árabe completo; anti-slop. → Reescribir tokens a paleta propia: fondo blanco perla + negro #0a0608 + oro brillante.
2. **awwwards-skill** (Z4YT0N) — **ADAPTAR:** su arquetipo *Luxury/Fashion* ya trae la receta exacta negro/crema/oro (#0a0608 / #f4f2ee / **#c4a882**) y reglas de pacing ceremonial. Copiar su sección "ARABIC TYPOGRAPHY RULES" y el token de oro.
3. **arabic-design** (JamalMohafil) — **ADOPTAR** siempre que haya texto árabe: garantiza caligrafía/letras conectadas sin romperse. Un solo SKILL.md.
4. **typeui.sh `premium` + `refined` + `editorial`** — **ADOPTAR** como sistema de tokens listo (`npx typeui.sh pull premium`). Refined usa Playfair Display (serif lujo) — combinar con fuente árabe (IBM Plex Sans Arabic / Noto Kufi).
5. **arabic-content-studio → `logo-designer` + `arabic-brand-voice`** (smeseik) — **ADAPTAR** el workflow de identidad (research→conceptos→SVG→brief) para el branding de la academia; sus references incluyen *color-psychology con matices del mercado árabe* (oro=lujo, negro=elegancia, blanco=pureza).
6. **Generación algorítmica de geometría islámica** (girih / estrella 8 puntas / zellij — Kaashi, papers, d3.js) — **ADAPTAR** para crear un **patrón arabesque propietario en SVG** (brand asset único, no stock) con trazos de oro sobre blanco/negro.
7. **Brand Build Skills (rampstackco) / Brand Guidelines (Anthropic)** — **ADOPTAR** el patrón de *brand guidelines* para fijar la paleta oficial oro/negro/blanco y aplicarla de forma consistente a todos los artefactos.
8. **Crear skill propia: `artemichiko-elegance`** — composición final: tokens oro (#d4af37 brillante + #c4a882 apagado), blanco perla, negro cálido; tipografía serif + IBM Plex Sans Arabic; reglas RTL; patrones arabesque; reglas anti-slop (no oro genérico, no gradientes neón). Basada en `skill-creator` de Anthropic. **Esta es la que aplica la dirección de diseño de forma durable.**

## 4. Inspiración de estética de lujo árabe/persa aplicable

### 4.1 Arabesque / Eslimi
- Línea vegetal entrelazada (viticci / eslimi persa) — patrón de follaje continuo que simboliza lo infinito. Uso web: **divisores dorados finos**, ornamentos de esquina en héroes, marcos de sección. Referencia visual: Google Arts & Culture "Organic Patterns" (URL §1.1); Pinterest "Persian Eslimi" (https://www.pinterest.com/sarahsaniee/persian-eslimi/).
- Aplicación: un *arabesque de 1px en oro* sobre blanco = lujo discreto (más elegante que el oro recargado).

### 4.2 Caligrafía árabe
- Estilos: **Thuluth** (ornamentado), **Diwani** (curvas), **Kufi** (geométrico). La "tradición árabe moderna" para marca = caligrafía estilizada como logotipo (casos: joyería de lujo, Al Trad).
- Fuentes web reales: **Amiri** (naskh editorial), **Reem Kufi** (geométrica), **Aref Ruqaa**, **IBM Plex Sans Arabic** (UI), **Noto Kufi Arabic** (base), **Cairo/Tajawal** (modernas). [tavily: mega-frontend-design §13.2]
- Prompt de caligrafía dorada ya validado: "thick, polished 3D gold metal with intricate floral …" (URL §1.1).
- **Importante:** ArteMichiko es academia de arte — la caligrafía puede ser asignatura/asset, no solo decoración.

### 4.3 Geometría islámica
- Motivos clave: **girih** (nudo persa), **estrella de 8 puntas** (rub el hizb — símbolo del Corán, elegante y reproducible), **muqarnas** (bóvedas de panal, 3D), **zellij** (mosaico). [tavily: Wikipedia Girih]
- Base algorítmica: **Hankin "polygons in contact"** → octágonos en contacto dejan cuadrados residuales → estrella de 8. Fácil de programar en SVG para web (ver §3.6).
- Aplicación: **patrón de fondo en blanco/negro con acentos dorados**, rejilla de estrella de 8 puntas en divisores, favicon/monograma.

### 4.4 Oro
- Oro real de marca: **#C4A882** (oro apagado/latón, uso extenso) y **#D4AF37** (oro brillante, para acentos). La referencia awwwards confirma **oro metálico sobre negro cálido + crema** (URL §2).
- Efectos: **gold foil** (hoja de oro, alto contraste sobre negro), **guilloché** (grabado), shimmer muy sutil — nunca gradiente neón. Evitar "gradient text" (regla awwwards para lujo).
- **Blanco + negro + dorado**: la tríada es literalmente el lenguaje de "fine jewelry / haute couture / premium real estate" GCC (DubaiPro, Al Trad, Qatar Gold, Diriyah).

### 4.5 Referencias regionales concretas
- **Diriyah** (patrimonio saudí + lujo contemporáneo) y **NEOM** (futuro) — binomio heritage/avant-garde que casa con una academia de arte. 
- **Al Trad (Riad)** — "bold, regal, heritage"; uso de B/N fotográfico + oro en acentos.
- **Qatar Gold / A4DH (Emiratos)** — "Luxury Gold" como color semántico; motivos de arquitectura de Dubái.
- **Tendencia actual:** "heritage maximalism" (comentario de diseñadores en el grupo Al Trad) — pero ArteMichiko debería ir a **quiet luxury** (menos es más): el negro/crema/oro apagado, no el maximalismo.
